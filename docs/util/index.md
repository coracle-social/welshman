# @welshman/util

[![version](https://badgen.net/npm/v/@welshman/util)](https://npmjs.com/package/@welshman/util)

Types and helpers for Nostr events, addresses, filters, tags, and relays.

## What's Included

- **Events**: Create, validate, and sort Nostr events
- **Kinds**: Kind constants and classifiers
- **Filters**: Match, build, and merge filters
- **Tags**: Tag specs and value selectors
- **Addresses**: `kind:pubkey:identifier` and NIP-19 naddr handling
- **Relays**: Relay URL handling and the relay selection DSL
- **Lightning**: LNURL and BOLT11 helpers

Profiles, lists, handlers, and rooms are modeled in [@welshman/domain](/domain/).

## Installation

```
npm install @welshman/util
```
