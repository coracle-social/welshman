# What is Welshman?

Welshman is a nostr toolkit for building client applications. It powers [Coracle](https://coracle.social) and [Flotilla](https://flotilla.social).

Welshman is split into opt-in packages. An application that only parses content installs `@welshman/content`, and a full client starts with `@welshman/app` and adds lower-level packages as it needs them.
